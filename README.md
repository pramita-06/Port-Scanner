# Python Port Scanner

A lightweight multithreaded TCP port scanner written in Python.

## Features

- TCP Port Scanning
- Multithreading
- Domain Name Support
- IPv4 Support
- Fast Scanning

## Technologies

- Python
- Socket Programming
- Threading

## Installation

```bash
git clone https://github.com/yourusername/Port-Scanner.git
```

```bash
cd Port-Scanner
```

```bash
python scanner.py
```

## Example

```
Enter Target:
scanme.nmap.org

Port 22 OPEN
Port 80 OPEN
```
